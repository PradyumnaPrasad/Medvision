# Reading the alignment results (author's notes)

Numbers are in `alignment_eval.md` (generated by `scripts/train_alignment.py`). This file is the
interpretation, written after seeing them.

## What was built
A PyTorch Geometric GATv2 encoder over the 51-node knowledge graph, an MLP image tower over
frozen DenseNet-121 features, a multi-positive InfoNCE loss (duplicate label sets count as
positives) plus a node-level term, and a ChromaDB index of 7,335 labelled reference cases used
for similar-case retrieval. All of it runs in the app and degrades cleanly when the artifacts
are not built.

## What the results say
- **Image -> KG finding (AUROC).** Aligned 0.606 vs the classifier head 0.702 and a logistic
  regression probe 0.679, over the 13 findings all three cover. The alignment does **not** beat
  plain classification on this task.
- **Similar-case retrieval.** Precision@5 on abnormal queries: aligned 0.314, raw DenseNet
  features 0.294, random 0.140. Retrieval is far better than chance and slightly better than
  the unaligned features; the gain over raw features is small and was measured on one seed, so
  it should not be called significant.
- **Does the knowledge graph help?** Not measurably. With the graph edges removed (text + id
  features only) mean AUROC was 0.616 +/- 0.015 against 0.610 +/- 0.008 with them. A 51-node
  hand-built graph gives the GNN little structure to exploit; the node text and ids carry the
  signal. The node-level loss clearly helps node retrieval (hit@1 0.371 vs 0.263).

## Limitations that qualify every number
1. **Likely undertrained.** Every run reached the 80-epoch cap instead of stopping early, so
   validation loss was still falling. Longer training, tuned on the validation split only, may
   improve the aligned numbers; it has not been tried.
2. **Optimistic absolute scores.** The frozen image encoder (torchxrayvision `all`) was
   trained on NIH ChestX-ray14, the same source as this sample. Comparisons between rows are
   fair (same features, same split); absolute values will not carry to other hospitals.
3. **JPEG re-encoding.** Images came from the datasets-server as ~60 KB JPEGs, not the
   original PNGs.
4. **Label noise.** NIH labels are text-mined from reports and known to be noisy.
5. **Five findings were never aligned.** Lung Lesion, Fracture, Lung Opacity, Enlarged
   Cardiomediastinum and Hernia have no positives in this sample, so they are excluded from the
   node-hint index (15 of 19 findings are indexed).
6. **Deviations from the plan.** Image features come from the existing DenseNet rather than
   BiomedCLIP; the alignment is trained on label sets, not report-derived subgraphs (the NIH
   sample has no reports). Retrieval is supporting context and never changes the diagnosis
   ranking.

## Defensible claim
"We implemented the image-graph alignment and retrieval end to end and evaluated it against
honest baselines. Retrieval is clearly better than chance; the alignment did not outperform the
classifier or a linear probe, and the graph structure added no measurable benefit in this
experiment."
